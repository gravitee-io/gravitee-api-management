WARNING: Hazelcast is enabled (ratelimit.type=hazelcast or gateway.cluster.type=hazelcast)

{{- if hasKey $kafkaProbe "secured" }}

WARNING: gateway.kafka.probe.secured is deprecated. It is rendered as kafka.secured, which in port routing
mode is also the TLS setting of the Kafka listener itself. Set gateway.kafka.secured instead (any gateway
image) or, with APIM 4.14 or later, gateway.kafka.routingPortMode.secured.
{{- end }}
{{- if and $kafkaRoutingPortMode.secured (not $kafkaSecured) }}

WARNING: gateway.kafka.routingPortMode.secured is only read by APIM 4.14 or later.
An earlier image ignores it and serves the Kafka listener in plaintext. Also set gateway.kafka.secured to
true: it is read by every image, and ignored by APIM 4.14 and later when routingPortMode.secured is set.
{{- end }}
